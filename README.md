# ProQuiz

A Jeopardy-style quiz game for teams in the same room. The laptop runs the game, a TV shows the board, and every team uses a phone as a buzzer.

**Work in progress.** See [PLAN.md](PLAN.md).

## Running it (for now)

```sh
npm install
npm start
```

Open the host address it prints on the laptop. Phones on the same Wi-Fi open the phone address.
